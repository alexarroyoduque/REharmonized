# python3 wav_to_harmony_pause_fix.py rom-harmony-europe.gba config_wav_reharmonized.txt rom-output-test-europe.gba
# Format:
#   HARMONY_SONG_ID   WAV_PATH   auto|TEMPO
#
# HARMONY_SONG_ID can be decimal or hexadecimal (0x..). WAV_PATH is resolved
# relative to the current directory; quote it if it contains spaces. TEMPO
# is either "auto" (auto-pick) or a forced BB tempo byte (decimal or hex,
# 1-255) - use a forced value if a song's loop point clicks/pops or has a
# silence gap when tested in agbplay/mGBA.
#
# Optional 4th field:
#   HARMONY_SONG_ID   WAV_PATH   auto|TEMPO   auto|off|TARGET_RMS
#     auto        -> current default behavior (RMS target 0.45)
#     off         -> no gain applied, use the .wav at its own volume
#     TARGET_RMS  -> a number 0-1 (e.g. 0.30) to force a quieter/less
#                    saturated result than the default, or a value above
#                    0.45 for a louder/more saturated one
# Example: 4   "../music/04 prologue edit.wav" 100   0.30
#
# convert .mp3 to .wav
# ffmpeg -i input.mp3 -ar 11025 -ac 1 -sample_fmt s16 output.wav
