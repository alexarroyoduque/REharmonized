# Harmony of Dissonance - REharmonized custom .wav music replacement configuration
#
# python3 wav_to_harmony.py harmony.gba config_wav_reharmonized.txt [output.gba]
#
# Format:
#   HARMONY_SONG_ID   WAV_PATH   auto|TEMPO
#
# HARMONY_SONG_ID can be decimal or hexadecimal (0x..). WAV_PATH is resolved
# relative to the current directory; quote it if it contains spaces. TEMPO
# is either "auto" (auto-pick) or a forced BB tempo byte (decimal or hex,
# 1-255) - use a forced value if a song's loop point clicks/pops or has a
# silence gap when tested in agbplay/mGBA.
#
# Optional 4th field:
#   HARMONY_SONG_ID   WAV_PATH   auto|TEMPO   auto|off|TARGET_RMS
#     auto        -> current default behavior (default audio normalization 0.4 RMS)
#     off         -> no gain applied, use the .wav at its own volume
#     TARGET_RMS  -> a number 0-1 (e.g. 0.30) to force a quieter/less
#                    saturated result than the default, or a value above
#                    0.4 for a louder/more saturated one
# Example: 4   "../music/04 prologue edit.wav" 100   0.30
#
# Optional 5th field: LOOP_START_SECONDS (default 0 = existing whole-song loop).
# A positive value plays the intro once, then loops from that second to the
# WAV's end using a native PCM loop, independent of TEMPO. Must be before EOF.
# Keep field 4 (use auto for default normalization) when adding field 5.
# Example: 5   "../music/05 successor of fate (Juste Belmont's theme) edit.wav" 1 auto 12.2
#
# Optional 6th field: CROSSFADE_SECONDS (default 0 = disabled).
# Requires a positive field 5. Blends the final seconds with the loop's head
# and jumps past that blended head; each loop becomes this much shorter.
# Intro and source WAV stay unchanged. Must span at least 2 resampled samples
# and not exceed half the loop duration. Example: 12.4 0.05 = 50 ms crossfade.
